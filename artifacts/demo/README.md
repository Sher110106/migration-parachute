# Demo artifact

`execution-ui-replay.mp4` is a 179-second recording of the real Migration Parachute execution UI replaying the persisted adaptive run. It shows the real run state, phase strip, key-range progress, event log, persisted cursor, and recovery timeline.

`migration-parachute-demo.mp4` is a 150-second evidence-summary cut built from the same recorded baseline and adaptive replay evidence. It covers the failure, recovery, deterministic verifier, neatlogs before/after trace IDs, Entire checkpoint evidence, cfo.ai scenarios, and the local-fixture limitation.

The execution-UI recording is ready to upload to YouTube as an unlisted public link for the neatHack submission.
